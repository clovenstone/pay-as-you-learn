# Contributing to Pay As You Learn

Thanks for helping build open, affordable 11+ prep tooling.

## How to contribute

1. Open an issue describing a bug, proposal, or improvement.
2. Fork and create a feature branch.
3. Make focused changes with clear commit messages.
4. Add or update tests/docs as appropriate.
5. Open a pull request with rationale and screenshots/logs when relevant.

## Pull request checklist

- [ ] Change is scoped and explained
- [ ] Tests or validation steps included
- [ ] Docs updated where needed
- [ ] No sensitive data committed

## Code of conduct

Be respectful, constructive, and student-first.
