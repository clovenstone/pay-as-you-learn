# Development Guide (Planned)

This repository is in early setup stage.

## Intended local workflow

1. Install dependencies (TBD by selected stack).
2. Run API service locally.
3. Execute unit + integration tests.
4. Run evaluation tests for generation quality.

## Contribution expectations

- Keep PRs focused and small.
- Add/update tests for behavior changes.
- Document major architectural decisions.
- Prioritize question quality and student safety.
